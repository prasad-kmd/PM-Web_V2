# Accessibility Statement

PM-Web V2 is designed and engineered to be accessible and inclusive for all users, including those relying on assistive technology.

## Accessibility Features

- **Reader Options Panel**: Custom typography, font size controls, and line spacing adjustments for articles and documentation.
- **Keyboard Navigation**: Full keyboard tab-index support across floating navbars, sidebar controls, and modal drawers.
- **ARIA Standards**: Proper `aria-label`, `aria-current`, and `aria-hidden` attributes across interactive components.
- **Contrast & Theme Support**: High-contrast dark and light modes with custom accent color adjustments.

If you encounter accessibility barriers, please open an issue in our GitHub repository.
